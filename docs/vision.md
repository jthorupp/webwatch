# WebWatch vision

WebWatch aims to give developers a practical way to catch changes that make websites worse. It will be a CLI that fits into local development and automation workflows, with clear, actionable results.

The intended quality checks include:

- Crawling pages and links
- Browser-based checks
- Resource validation
- Visual comparisons

The first project milestone is a small, maintainable foundation. Scanning behavior and infrastructure choices are intentionally out of scope for this initial setup.
